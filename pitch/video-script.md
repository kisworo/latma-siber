## Yang harus terlihat jelas di video

1. **Timer generation** — tunjukkan hitungan detik, jangan dipotong.
2. **Papan skor bergerak** setelah kirim keputusan.
3. **WiFi dimatikan** lalu halaman di-refresh dan masih berfungsi. Ini bukti klaim "tanpa internet" — paling meyakinkan di seluruh video.
4. **Tidak ada API key / akun / login** di layar. Sistem berjalan lokal.

## Kalau waktu mepet

Rekam versi 90 detik: 0:00 hook (10s) → 0:10 generate (25s) → 0:35 dua inject + skor (30s) → 1:05 AAR (15s) → 1:20 WiFi mati (10s). Tetap penuhi syarat "video presentasi".
